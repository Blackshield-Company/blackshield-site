# Blackshield Company

Static site for Blackshield Company. Plain HTML/CSS, no build step.

The look is four colors only: black `#101014`, blood `#C1121F`, steel `#8F959C`
and bone `#D8D3C8`. The mascot is the Blackshield knight, five pixel states drawn on
32x28 frames (`assets/img/knight/`), animated with CSS steps in `style.css` and
driven by `assets/knight.js`. Under reduced motion every state holds its first frame.
