04 — Public benches

Open source

Public studio code lives in the Blackshield-Company GitHub org. Read it, use it, and send fixes. SentryClaw, wireclaw and open-synth are licensed Apache-2.0; check each repo for its license.

Modforge and Shieldwall will be open source when they ship.

AI coding tools

openshield

Open-source coding agent harness in Rust. Home of Knight A, the company mascot.

openshield-desktop

Desktop companion for OpenShield: sessions, streaming chat, tool approvals. Tauri 2 + SvelteKit.

openshield-mobile

OpenShield Pocket: Android companion that pairs with openshield serve over LAN.

sentryclaw

Self-hosted code review using local models. No cloud, no API keys. Rust + Axum. Apache-2.0.

agentbench

Self-hostable benchmark runner for coding agents. TUI + web dashboard. Rust.

ghostbin

Reverse engineering suite with LLM-assisted analysis. Rust + Capstone + Iced-x86.

Forensics & privacy

beacon

Interactive cybercrime evidence-preservation and reporting guide for victims.

custody

Tamper-evident chain-of-custody log for digital evidence.

docket

Local-first case file organizer for public defenders.

exifguard

Batch forensic EXIF verifier for evidence photos.

timeline

Evidence timeline builder for investigators and defense attorneys.

blotter

Normalizer and explorer for public crime and incident data.

scamshield

Offline scam pattern detector for elderly users and families.

Mesh networking

reticulum-hub

Web dashboard and management platform for Reticulum networks.

reticulum-beacon

Personal Reticulum transport node and service hub.

reticulum-wave

Cross-platform encrypted mesh messaging client for Reticulum/LXMF.

reticulumchat

TUI chat client over Reticulum with voice and file sharing.

Dev & CLI tools

wireclaw

Local HTTP proxy to capture, replay and inspect API traffic. Rust CLI + TUI. Apache-2.0.

tapeworm

TUI log analyzer with live tail, grep, aggregation and histograms. Rust.

trackerclaw

Privacy-first time tracker: local, no cloud, no accounts.

loopback

Self-hosted webhook testing tunnel with replay and inspection. Elixir.

splice

Minimalist version control for binary assets. C.

signalscope

SDR spectrum analyzer and demodulator TUI with RTL-SDR support.

Games & engine

voidengine

Game engine with hot-reload and data-driven design. Odin + SDL2.

void-mercs-demo

Free demo of Void Mercs, built on VoidEngine. v0.1.1 is a pre-release; the Windows build has only been tested under Wine. The full game is coming to Steam. Void Mercs is all rights reserved.

Knight A

The company mascot: five animated pixel states (idle, thinking, working, success, error). Generator lives in openshield.

Audio

open-synth

Open-source synthesizer and sample ROMpler on a JUCE 8 / C++20 engine. Standalone, VST3 and CLAP. Apache-2.0.

omarchy-blackshield

cachyos-blackshield

CachyOS theme pack: KDE Plasma, terminals, nvim, boot splash, wallpapers.

cachyos-synthwave84

Synthwave '84 theme set for CachyOS: KDE, Limine, Plymouth, terminals, icons.

blackshield-icon-pack

Android icon pack: dark steel tiles, bone glyphs, one blood accent.

blackshield-clock-widget

Linux gaming

Desktop companion for the Daedric Online Skyrim RP server.

The founder

Built by synth.

Blackshield Company was founded in 2026 by synth (synthalorian). synth works on Omarchy Linux and builds the tools the studio wants to use. It is one person and a lot of shipped code: Rust coding tools like OpenShield and SentryClaw, forensics and privacy software for victims and public defenders, Reticulum mesh networking, the VoidEngine game engine and Void Mercs, the open-synth synthesizer, Linux and Android themes, and fifteen Skyrim mods on Nexus.

Our mission: "To better ourselves, each other, and AI, under God."

Most of the work is open source and free. The mods are free, and anything still in beta says so. The shop opens soon.
