Open source

AI coding tools

openshield

Open-source coding agent harness in Rust.

openshield-desktop

Desktop companion for OpenShield: sessions, streaming chat, tool approvals. Tauri 2 + SvelteKit.

openshield-mobile

OpenShield Pocket: Android companion that pairs with openshield serve over LAN.

sentryclaw

Self-hosted code review bot using local models. Rust + Axum.

agentbench

Self-hostable benchmark runner for coding agents. TUI + web dashboard. Rust.

ghostbin

Reverse engineering suite with LLM-assisted analysis. Rust + Capstone + Iced-x86.

Forensics & privacy

docket

Local-first case file organizer for public defenders.

exifguard

Batch forensic EXIF verifier for evidence photos.

timeline

Evidence timeline builder for investigators and defense attorneys.

blotter

Normalizer and explorer for public crime and incident data.

scamshield

Offline scam pattern detector for elderly users and families.

Mesh networking

reticulum-hub

Web dashboard and management platform for Reticulum networks.

reticulum-beacon

Personal Reticulum transport node and service hub.

reticulum-wave

Cross-platform encrypted mesh messaging client for Reticulum/LXMF.

reticulumchat

TUI chat client over Reticulum with voice and file sharing.

Dev & CLI tools

wireclaw

Local HTTP proxy for API traffic capture, replay and inspection. Rust CLI + TUI.

tapeworm

TUI log analyzer with live tail, grep, aggregation and histograms. Rust.

Self-hosted webhook testing tunnel with replay and inspection. Elixir.

Minimalist version control for binary assets. C.

SDR spectrum analyzer and demodulator TUI with RTL-SDR support.

The founder

Built by synth.

Blackshield Company was founded in 2026 by synth (synthalorian), a developer on Omarchy Linux who builds the tools the studio wants to use. One person, a lot of shipped code: Rust AI coding tools like OpenShield and SentryClaw, forensic and privacy software for victims and public defenders, Reticulum mesh networking, the VoidEngine game engine and Void Mercs, the open-synth synthesizer, Linux and Android themes, and fifteen Skyrim mods on Nexus.

The mission: to better ourselves, each other, and AI, under God.

Most of it is open source and free. Mods on Nexus are free, and anything still in early beta is labelled beta. The shop isn't open yet.
